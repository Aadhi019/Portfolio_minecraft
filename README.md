# Portfolio_minecraft

An authentic Minecraft RPG-themed interactive developer portfolio for **Bala Aadhityaa K** — AI and Full-Stack Developer.

> *"Explore Bala's World — Build. Code. Create."*

---

## 🌟 Features

- **9 Interactive Biomes & World Environments**:
  - **Slot 1 [Spawn]**: Overworld sunrise hero portal and verified credentials.
  - **Slot 2 [Profile]**: RPG Character sheet with Steve head, combat scores, loadout, and attributes.
  - **Slot 3 [Skills]**: Enchanting Table library with Lapis categories and arcane hover tooltips.
  - **Slot 4 [Projects]**: Mineshaft Chest featuring **LifeOS** (Personal Chief of Staff) and **FallGuard** (IoT Fall Detection System).
  - **Slot 5 [Journey]**: Snowy Peaks Crafting Table timeline (B.Tech CSBS 7.08%, Diploma 80.5%, SSLC 71.2%).
  - **Slot 6 [Achievements]**: Deep Dark Advancement frames, trophies, and certifications.
  - **Slot 7 [Services]**: Village Post villager trading desk with emerald fees and work inquiries.
  - **Slot 8 [Contact]**: Lush Caves Book & Quill contact dispatch form.
  - **Slot 9 [The End]**: The End Void dimension with level-up climax and respawn mechanics.
- **Authentic Minecraft HUD**:
  - Pixel-perfect Hardcore Hearts and Hunger shanks.
  - Authentic 182×5 ratio 18-segmented XP Bar with dynamic leveling to Level 30 at The End.
  - Real-time local clock and live RAF frame rate monitor.
  - Web Audio API retro Minecraft sound synthesis (Hurt, Eat, Pop, Enchant, Level-Up).
- **Recruiter Fast Mode**:
  - Instant executive dossier modal for recruiters to scan resume data in seconds.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: TailwindCSS v4 + Vanilla CSS Design System
- **Icons & Graphics**: Lucide React + Custom 3D Isometric Voxel assets
- **Effects**: Web Audio API Sound Synthesizer + Canvas Confetti
- **Typography**: Silkscreen, VT323, Outfit

## 🚀 Getting Started

### 1. Clone & Install
```bash
git clone https://github.com/Aadhi019/Portfolio_minecraft.git
cd Portfolio_minecraft
npm install
```

### 2. Development Server
```bash
npm run dev
```
Open `http://localhost:5173/` in your browser.

### 3. Production Build
```bash
npm run build
```
